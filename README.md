# Stock Assistance

Streamlit 기반 투자 대시보드입니다.

## 웹 배포/업데이트 방법

1. 이 저장소의 변경사항을 GitHub에 Push합니다.
2. Streamlit Community Cloud 또는 다른 웹 호스팅 서비스에서 이 저장소를 연결합니다.
3. 앱이 다시 빌드/재배포되면 웹 화면에 반영됩니다.

### 실행 방법 (로컬)

```powershell
cd c:\민병우\공부\3. 코디세이\Stock_Assitance
streamlit run app.py
```

### 웹에서 반영되게 하려면

- 로컬 수정만 하고 브라우저 새로고침을 해도 웹에는 반영되지 않습니다.
- 반드시 GitHub에 Push한 뒤, 배포 서비스에서 재배포를 실행해야 합니다.
